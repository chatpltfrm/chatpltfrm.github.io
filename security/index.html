Memenuhi persyaratan UU Pelindungan Data Pribadi

  • Data disimpan di server di Indonesia

    Pesan, berkas, dan data akun layanan Cloud disimpan dan diproses di server yang berada di wilayah Republik Indonesia.

  • Tanpa AWS, Google Cloud, atau Azure – Telegraf menggunakan penyedia cloud lokal

    Telegraf di-hosting pada penyedia cloud lokal di Indonesia, bukan pada AWS, Google Cloud, atau Microsoft Azure.

  • Telegraf tunduk pada hukum Indonesia

    Sebagai perusahaan Indonesia, PT. Chat Platform Indonesia tunduk pada hukum Indonesia, termasuk UU No. 27 Tahun 2022 tentang Pelindungan Data Pribadi. Karena data tidak di-hosting oleh penyedia cloud asal Amerika Serikat, data tersebut tidak berada di bawah kendali penyedia yang tunduk pada CLOUD Act.

  • Tanpa alat pelacak eksternal

    Telegraf tidak menggunakan alat pelacak eksternal, seperti Google Analytics atau layanan berbasis alamat IP. Data yang dikumpulkan hanya diproses oleh Telegraf.
